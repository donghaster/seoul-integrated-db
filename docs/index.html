데이터 안내

실거래 자료(아파트·연립다세대·단독다가구·상가·오피스텔)는 국토교통부 실거래가 공개시스템(공공데이터포털)에서 내려받은 원본을 집계한 것으로, 표본 기간은 각 대시보드 상단에 표기됩니다. 실거래 신고는 계약일로부터 30일 이내이므로 최근 1~2개월 자료는 계속 추가됩니다. 정비사업(뉴타운) 진행상황은 공개 자료를 정리한 참고용이며, 실제 계약·투자 판단 전에는 조합·구청 고시 등 원문 확인이 필요합니다. 상권분석(유동인구·점포·추정매출)은 서울 열린데이터광장 상권분석서비스의 분기 통계이며 추정치입니다.
