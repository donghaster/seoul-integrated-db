# 금집부쌤의 서울시 통합 부동산 대시보드

반포114공인중개사(010-9442-2027) 고객 브리핑용 실거래 현황판.
`dh-chi.vercel.app`의 3종 대시보드를 **서울시 25개 자치구 전역**으로 확장해 새로 만들었습니다.

```
docs/                     ← 이 폴더만 배포하면 됩니다 (정적 사이트)
  index.html              대시보드 모음(랜딩)
  newtown/                🏙️ 뉴타운 대시보드
  apt/                    🏘️ 아파트 대시보드
  sangga/                 🏢 상가·오피스텔 대시보드
  shared/app.css          공통 스타일 + 인쇄(워터마크) 규칙
  shared/brand.js         조회시각·섹션이동·섹션인쇄·TOP10 탭 전환
  data/                   자동 생성 데이터 (apt.js / sangga.js / geo.js) + newtown.js(수기)
  assets/                 금집부쌤 로고 · 반포114 로고 · 금똑이
  vendor/chart.umd.min.js Chart.js 4.4.4
tools/                    데이터 수집·집계 스크립트
```

## 화면 구성

| 대시보드 | 범위 | 주요 내용 |
|---|---|---|
| 뉴타운 | 서울 재정비촉진지구 27개 지구 (19개 자치구) | 지구별 진행단계·지도, 노량진/흑석/신길은 구역별 상세, 소재 법정동 실거래 연동 |
| 아파트 | 서울 25개 자치구 · 367개 지역(구+법정동) | **TOP10 3종 전환 버튼**, 실거래 지도, 입지분석, 정책 |
| 상가·오피스텔 | 서울 25개 자치구 | 상가·업무용 TOP10, 오피스텔 TOP10, 거래량 비교, 수익형 입지분석 |

### TOP 10 전환 버튼 (아파트 대시보드)

`아파트 실거래가` / `매매·전세·월세 가격비교` / `아파트 실거래량` 세 섹션은
길게 이어 붙이지 않고 **상단 버튼 3개로 한 화면에서 돌아가며** 봅니다.

- 화면: `section[data-tabpanel]`은 `.is-on`일 때만 표시
- 인쇄: `@media print`에서 `section[data-tabpanel] { display: block !important }`
  → **전체 인쇄하면 3종이 모두 출력**됩니다.

### 인쇄

- `🖨️ 전체 인쇄` — 전 페이지에 **반포114공인중개사 워터마크**(`.print-watermark`, `position:fixed`)
  와 우상단 **반포114 로고 + 금똑이 플레이트**가 반복 인쇄됩니다.
- `이 섹션 인쇄` — 해당 섹션만 출력합니다.
- 1페이지 상단에 조회 지역·표본 기간 배너가 자동으로 붙습니다.

## 데이터 갱신

국토교통부 실거래가(공공데이터포털) + 카카오 로컬 API 키가 필요합니다.
키가 없으면 옆 폴더 `../seoul dashboard/.env`를 자동으로 읽습니다.

```bash
py tools/fetch_molit.py     # ① 서울 25개 구 × 12개월 × 5종 원본 수집 → .cache/
py tools/build_data.py      # ② 집계 → docs/data/apt.js, sangga.js
py tools/build_geo.py       # ③ TOP10 단지 좌표 → docs/data/geo.js
```

- `fetch_molit.py`는 **월 단위 캐시**라 중간에 끊겨도 다시 실행하면 이어받습니다.
- 공공데이터포털이 429(요청 과다)를 주면 자동으로 물러섰다 재시도합니다.
  더 느리게 받으려면 `WORKERS=2 MIN_INTERVAL=0.6` 환경변수를 주세요.
- 기간을 바꾸려면 `MONTHS=24`, `END_YM=202606` 환경변수를 씁니다.

`docs/data/newtown.js`는 **수기로 관리**하는 정비사업 정리 파일입니다(자동 생성 아님).

## 데이터 안내

- 실거래 표본: **2025.08 ~ 2026.07 (12개월)** · 아파트 315,084건 / 상가·오피스텔 116,810건
- 실거래 신고는 계약일로부터 30일 이내이므로 **최근 1~2개월은 계속 추가**됩니다.
- 상업·업무용 실거래는 지번 일부가 **비공개(예: 1**)** 로 제공되어 지도에 표시하지 않습니다.
- 상업용 평당가는 **건물 연면적** 기준이라 아파트 전용면적 평당가와 직접 비교할 수 없습니다.
- 뉴타운 진행상황은 공개 자료를 정리한 **참고용**이며, 구역별 인가일·시공사·세대수는
  조합·구청 고시 원문으로 확인해야 합니다.
